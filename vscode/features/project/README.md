# Project results

Refresh scans the open project for saved C1, C3, C4, C5 and cosim JSON files. The scan stops at 500 paths. Open Saved Result selects a file directly. Expand a result for all recorded fields. Bundle summaries show last progress. Cosim summaries show the first mismatch PC. Use the row context menu to open a declared trace or recorded source location. Source jumps use captured locations without identity checks. Missing files show an error. This feature does not start runs or establish verdicts.
