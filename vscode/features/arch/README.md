# Architecture reports

Open Designer Report reads saved perf, arch run, arch compare or OoO model JSON. Open Component Study reads saved csim sweep and compare JSON. The webview shows recorded counters, IPC, producer attribution when present, study rows, errors and full limits. Missing top-down or bottleneck fields stay unavailable. Model observations do not establish hardware top-down metrics or RTL correctness. This feature starts no study or simulation. It uses plain tables and no UI framework.
