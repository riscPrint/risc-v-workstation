# Findings from the collected work

These are reported observations. This document audit did not rerun them. A failed check does not by itself locate a core bug. Sources give the exact configurations and limits.

| Target | Finding | Scope and limit | Recording PR |
|---|---|---|---|
| Spike Debug Module | Reported no `haltsum0`, retained `data0` across `dmactive=0`, ignored `aarpostincrement`, and interrupts while stepping without implemented `stepie`. | Reference implementation observations. Profile skips carry reasons. No real RTL debug endpoint was tested. | [#455](https://github.com/riscPrint/risc-v-workstation/pull/455) |
| Spike with OpenOCD | Hardware breakpoint and watchpoint checks fail. Spike resets trigger type to 15. The tested OpenOCD skips type-15 triggers. | Specific Spike/OpenOCD versions. This does not qualify a core Debug Module. | [#473](https://github.com/riscPrint/risc-v-workstation/pull/473) |
| VexRiscv interrupt entry | With `mtval=7`, MSIP and MTIP comparison retains a mismatch. Spike expects zero. RTL reports 7. | Both zero-initialized positive controls match. No mask or fabricated value hides the difference. | [#705](https://github.com/riscPrint/risc-v-workstation/pull/705), [#721](https://github.com/riscPrint/risc-v-workstation/pull/721) |
| VexRiscv DPI capture | Yielding before sampling could miss a retirement at interrupt entry. | Sampling trap, RVFI and CSR state before DPI yield fixes the observed transport defect. General interrupt compliance remains open. | [#705](https://github.com/riscPrint/risc-v-workstation/pull/705) |
| VexRiscv generated checks | All 49 ISA programs completed. All 49 C1 results stayed failed. Eleven internal fetch valid-hold checks fired 8,768 times. The other 46 inserted checks had zero firings. | Source inspection suggests cancellable flush/halt offers. Cancellation was not independently traced. Resolve the checker contract before calling this a core defect or a clean qualification. | [#840](https://github.com/riscPrint/risc-v-workstation/pull/840) |
| PicoRV32 architectural monitor | Bounded comparison fails at cycle 10 on a misaligned JAL. Native RVFI retains a destination write on the trap. The monitor suppresses it and detects the changed register frame. | Three 30-retirement simulations matched. They do not override the formal counterexample. No equivalence certificate was granted. | [#838](https://github.com/riscPrint/risc-v-workstation/pull/838) |
| VexRiscv security export | Real-core two-copy and IFT attempts are inconclusive before solving. `check -assert` finds two undriven `CsrPlugin_stvec_mode` bits. | No bypass assumptions or constants were added. This is an export/input limit, not a security proof or demonstrated leak. | [#842](https://github.com/riscPrint/risc-v-workstation/pull/842) |
| Avy | Native probes reproduce SIGSEGV on a zero-latch folded HWMCC input. Diagnostics retain zero-latch and multi-output classes. | Internal root cause is not established. This is not a claim that all Avy inputs fail. | [#797](https://github.com/riscPrint/risc-v-workstation/pull/797) |
| rIC3 | `rlive` reports an internal removed-option CLI mismatch. An earlier BMC attempt also exposed old SBY bounded flags. | Errors remain inconclusive. Other liveness reductions have separate evidence. | [#797](https://github.com/riscPrint/risc-v-workstation/pull/797), [#476](https://github.com/riscPrint/risc-v-workstation/pull/476) |
| Formal portfolios | The 43 VexRiscv models earned no qualified solve or abstraction gain in the reported short campaigns. State cuts produced five abstract failures and 38 witness reconstruction errors. | Different stage limits prevent a speed comparison. PicoRV32 native passes under unchecked restrictions remain qualified inconclusive. | [#810](https://github.com/riscPrint/risc-v-workstation/pull/810), [#802](https://github.com/riscPrint/risc-v-workstation/pull/802) |
| Verilator SV functional coverage | Tested transition bin emitted `COVERIGN` and failed its coverage assertion. The tested 4-bit `randc` cycle passed. | Version-specific engine gap on the recorded 5.049 development build. Python coverage transport does not establish SV language support. | [#618](https://github.com/riscPrint/risc-v-workstation/pull/618) |
| SV protocol fixtures | Native gaps include AXI B response before a complete monitored write, TileLink unexpected response, UART frame mismatch and an AHB malformed-manager diagnostic mismatch. | Thirteen fixtures passed three good and three corrupt seeds. The remaining gaps are not attributed to an engine bug. | [#853](https://github.com/riscPrint/risc-v-workstation/pull/853) |
| Architecture models | Held-out VexRiscv fit errors were +3.41%, +11.34%, -6.20%. VexiiRiscv errors were -23.57%, -30.13%, -4.76%. | Six programs per core. General accuracy remains inconclusive. Vexii lacks probe event correlation. | [#862](https://github.com/riscPrint/risc-v-workstation/pull/862) |
| Native adapter performance | Snapshots improved CPU throughput by 1.222x in the follow-up. Wall throughput ratio was 0.862. | No wall-time gain from snapshots was qualified. The separate 25.08x suite result measures persistent JVM reuse on one warmed 49-test sample. | [#849](https://github.com/riscPrint/risc-v-workstation/pull/849) |

The full source ledger is [PR_EVIDENCE.md](PR_EVIDENCE.md). The per-issue notes retain additional NOT RUN statements, failed attempts and known limits. Findings here must not become issue closures without acceptance review.
