## Python lock

`scripts/install.sh` uses `uv sync --locked`. Development setup uses
`uv sync --locked --extra dev --extra mcp --project rvw`.
Update dependencies with `uv lock --project rvw` in a reviewed change.
Optional cocotb, pyuvm and wellen extras are in the same lock.

## Native version checks

The installer refuses missing tools, versions below its minimum, JDK outside
major 21 and gem5 outside 25.1.0.1 or without RISC-V support.
Unknown versions fail. Versions outside the observed table warn.
Verilator 5.049 has a known FSM coverage crash. Keep FSM coverage disabled.
Host package versions can drift. Source pins do not make builds bit-for-bit
reproducible. Presence and version probes do not test a tool flow.

Linux recipes and native qualification remain open under #17. Complete
reproducible combinations remain open under #40. Bundles remain under #71.
