## Open edges, ranked by effect on a new core

1. **Input capture before regression.** `regress run` refuses an incomplete
   declaration before simulation. The guide must state this before its first
   regression command. Direct adapter runs are the development path.
2. **Shared sbt build queue.** Repeated external adapter invocations compile
   through the shared lock. This run waited behind up to eleven jobs. The
   project uses an explicitly selected compiled classpath for later runs. All
   runtime class directories and JARs must be captured. Rebuild after edits.
3. **Generated RTL identity.** This integration issue was resolved by adding
   `generatedVerilog(model)` as well as `elaborate`. The guide now states both
   requirements. The scaffold cannot infer the file list for an arbitrary
   compiled model. Keep the mismatch check.
4. **Consistent elaboration configuration.** A no-argument top class does not
   carry the simulation's clock/reset configuration into `spinaldb.Main`.
   Use one project-owned entry for the same configuration. The observed ASYNC
   versus SYNC mismatch blocked both formal and IFT.
5. **Core correctness before suite scale.** The scratch core initially omitted
   `mie`, which trapped repeatedly in the riscv-tests environment. This is a
   core defect, not a workstation failure. A smoke match is insufficient.
6. **Bus bridges and bindings.** A custom CPU bus does not directly fit the
   APB3 SoC composer or the UVM supported-bus profiles. The scaffold does not
   implement a bridge. Idle-source generation is not CPU integration.
7. **RV32I architecture descriptions.** The current in-order model selection
   requires RV32IM. There is no measured architecture-model result for this core.
8. **VIP command surface.** There is no standalone `rvw vip` CLI or MCP family.
   Use the documented library APIs after binding a supported protocol.
9. **Probe completeness.** This project's missing fetch flush and stall probes
   leave open entries and unknown commit bubbles. Perf reports retain those gaps.
