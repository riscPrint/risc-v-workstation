# TileLink A channel. The D$ MSHR file merges its A-channel requests with rocket-chip's TLArbiter.lowest
# (mshrs.scala:719), which re-arbitrates every cycle until the sink is ready: a stalled single-beat
# AcquireBlock (source 1) is replaced by a lower-index MSHR's (source 0, another line) before acceptance
# (qsort, seed 1, cycle 13001). Legal TileLink (rocket's TLMonitor checks only multi-beat bursts), so the
# generic Spinal Stream rule is waived on the three ids it fired on. The TileLink rule
# `tilelink.burst_stable` (same header on every beat of a burst, stable payload while a beat inside a
# burst is stalled) stays active on these channels. A Spinal TileLink slave that latches a request on
# `valid` before `ready` would still see it change: reported, not changed (core code).
stream.payload_stable:io_mem_a                       rocket TLArbiter re-arbitrates a single-beat A request until ready (legal TileLink; tilelink.burst_stable stays on)
stream.payload_stable:arbiter.io_ups_0_a             same A-channel beat, at the Spinal tilelink.Arbiter input (tilelink.burst_stable stays on)
stream.payload_stable:arbiter.a_arbiter.io_inputs_0  same A-channel beat, inside the Spinal tilelink.Arbiter (tilelink.burst_stable stays on)
