# Custom instruction examples

`xadd.json` defines pure version-1 arithmetic. `effects.json` defines version-2
extra-state, memory and trap effects. Each has explicit reference vectors and
mutants. Neither file qualifies a real core.

`compiler-bases.json` pins five source files from GCC revision
`5115c7e447fc07457443df874bf57840e8316d5f` and LLVM revision
`3623fe661ae35c6c80ac221f14d85be76aa870f1`. Place the files at their listed paths
under a base directory. Copy this manifest there as `sources.json`.

Custom ISA backend scaffolding (`rvw/src/rvw/cosim/custom.py`, `examples/custom-isa/xadd.json`); the standalone `formal custom-isa` CLI subcommand was trimmed.

The generated `backends/gcc.patch` and `backends/llvm.patch` include the parent
integration. `compiler-patches/` holds the generated RV32I example patches.
They have been checked for application to the pinned source files. GCC/LLVM
builds are NOT RUN.

Use the generated Spike build script with the shim's Spike prefix. It produces
an extension library and a platform fragment for explicit project selection.
The native smoke tests cover GNU RV32I/RV64I calling conventions and matching
Spike instruction handlers. They do not exercise a DUT.

Upstream compiler license IDs are recorded in generation metadata. The generated
artifact license is not specified. The installed Spike dependency license is
not verified. Version-2 effect backends are not generated by the pure command.
